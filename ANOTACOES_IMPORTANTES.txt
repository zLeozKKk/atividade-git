Master/main : Onde o código final fica, é a principal BRANCH

Origin : nome genérico que o Git usa para apelidar o repositorio que está no GitHub.

BRANCH TEMPORÁRIA: feature/nome, branch de testes, para não estragar a principal.

REPETIÇÃO DIÁRIA

BRANCH temporária , edição commit e envio no github

unir as duas BRANCH MERGE

ENVIAR A.

---

# Checagem de Estado
git status
git branch

# Fluxo de Feature Branch
git checkout -b feature/nome-da-tarefa
git add .
git commit -m "Descricao das alteracoes"
git push -u origin feature/nome-da-tarefa

# Fusao na Trunk (Master)
git checkout master
git merge feature/nome-da-tarefa
git push origin master

# Resolucao de Conflitos
git checkout --ours NOME_DO_ARQUIVO
# ou ajuste manual via marcas de conflito no VS Code

# Historico
git log : historico geral com autores
